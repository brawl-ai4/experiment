🎮 About HyperRush

Welcome to HyperRush Games - your ultimate destination for free online gaming!

✨ Features:

  • Wide Game Selection: Browse hundreds of games across multiple categories
  • Quick Hide: Press Ctrl+Q to instantly hide the page
  • Dark/Light Mode: Toggle between themes with one click
  • Search & Filter: Find games quickly by name or category
  • Smooth Design: Modern, responsive interface that works on all devices

⌨️ Keyboard Shortcuts:

  • Ctrl+Q: Quick hide (about:blank)
  • Ctrl+/: Focus search
  • Enter: Play selected game

🚀 Tips:

  • Use categories to organize games by type
  • Search for specific games by name
  • Hover over cards to see more details
  • Toggle between grid and list view
